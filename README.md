# Link Inspector

Static GitHub Pages site for local URL validation and domain recognition for LootLabs and Platorepay.

## Features
- Responsive interface for mobile and desktop
- Local URL validation in the browser
- Recognizes supported hostnames
- Open the original URL or copy it
- No URL is submitted to a backend

## Limitations
GitHub Pages serves static files only. This project does not bypass advertising tasks, defeat access controls, or extract protected destinations. Use official platform APIs where permitted.

## Deploy
Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/(root)`.
